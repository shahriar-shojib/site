# shojib.dev

My personal site: a dithered dot-art Auckland that follows the real sun and moon.

TanStack Start, Solid and motion. Every page is prerendered to static HTML in `dist`.

```bash
pnpm install
pnpm dev     # http://localhost:3000
pnpm build   # static site in dist
```

Pushing to `master` deploys to Cloudflare Pages.

The scene's approach owes a lot to [daoho.dev](https://daoho.dev) and [ascii-sharks](https://github.com/stackedlol/ascii-sharks), both MIT.
